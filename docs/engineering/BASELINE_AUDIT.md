# Lemma engineering audit

Date: 2026-10-14. Scope: current working tree, including pre-existing uncommitted editor changes. This audit preceded installation of the engineering kit. Findings are source observations or explicitly labeled risks; no application fixes, migrations, deployments, or production data changes were made.

## Prioritized findings

| Priority             | Finding and evidence                                                                                                                                                                                                                                                                                                                  | Impact / next action                                                                                                                                                                                                                                                               |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| P1                   | Draft coverage is incomplete. `Editor.tsx` writes a draft in `onUpdate`, but `rename` updates React state without writing a recovery draft. The 750ms autosave timer is canceled on active-note changes.                                                                                                                              | A quick note switch or reload can lose a renamed title. Route persisted mutations through a small draft-and-save helper; test rename → switch before debounce and reload offline.                                                                                                  |
| P1                   | Saves are not ordered. The autosave effect clears timers but cannot cancel an already running `repository.save(active)`. Explicit create/share saves can also overlap autosave. Success unconditionally sets the global saved indicator.                                                                                              | Slow/out-of-order responses or concurrent tabs can overwrite newer content or show a stale success. Propose per-note save ordering and an explicit conflict policy; test delayed first save, newer edit, note switch, and two clients before changing persistence.                 |
| P1                   | Deletion has no durable retry or rollback. `deleteCurrent` removes UI state and the local draft before awaiting the cloud delete; on failure it only sets offline. Folder recovery similarly merges cached folders missing remotely.                                                                                                  | A failed delete can reappear on refresh; stale device folder caches can recreate remotely deleted folders. Propose tombstones/retry or restore-on-failure, and verify folder/note cascade behavior. Approval required for persisted-format migration.                              |

- `./node_modules/.bin/tsc --noEmit`: passed; core `@ts-nocheck` modules remain unchecked.

- `npm run format:check`: failed on pre-existing `output/playwright/verify.html`, `output/playwright/verify.tsx`, `public/lemma-verify.html`.
- `npm run lint`: interrupted after a prolonged repository-wide scan with no diagnostics; `.vercel` output is not excluded by ESLint. `./node_modules/.bin/eslint src vite.config.ts vitest.config.ts eslint.config.js` completed with 53 problems (33 errors, 20 warnings), including existing `@ts-nocheck`, explicit-any and hook issues. The lint command was wrapped to capture diagnostics; ESLint reported failure even though the shell wrapper returned success.

Installed local dependencies were used; no dependency install or lockfile changes. Full command logs were held in `/tmp/lemma-audit-*.log` for this session. No browser screenshots, screen-reader evaluation, live database queries, negative authorization tests, dependency vulnerability scan, legal review, backup restoration, or deployment check were performed.

## Recommended sequence and boundaries

1. Reproduce draft/save/delete failures and verify live authorization in an isolated environment.
2. Approve a small persistence proposal with acceptance tests and rollback before introducing conflict or deletion state.
3. Add meaningful quality gates and incremental typing; verify auth/config failure UX.
4. Complete operational/privacy facts and inspect UI/print/accessibility in a browser.
5. Propose measured performance and CSS cleanup separately.

This task installs documentation, local skills, inventories and inert references only. Broad refactoring, redesign, destructive operations, production-sensitive changes and persisted-data migrations require explicit approval. Existing Lovable history must remain intact.
