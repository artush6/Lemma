# Ui And Motion

- [ ] Consistent global page shell and navigation
- [ ] Tokenized spacing and typography without arbitrary proliferation
- [ ] Uniform form labels, errors, buttons and disabled states
- [ ] Mobile and desktop widths inspected in actual browser where possible
- [ ] Accessible focus, semantics, contrast, tap targets and keyboard use
- [ ] Purposeful hover, tap, loading and view transition feedback
- [ ] Reduced-motion fallback and no distracting animation
- [ ] Empty/loading/error/partial/success states
- [ ] No uncontrolled layout shifts or broken overflow
- [ ] No duplicate superseded components after safe cleanup
